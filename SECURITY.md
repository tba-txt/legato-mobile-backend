# Política de Segurança - Legato API

A equipe de desenvolvimento do Legato leva a segurança a sério. Este documento descreve nossos procedimentos de segurança e como relatar vulnerabilidades encontradas em nossa aplicação.

## Versões Suportadas

Atualmente, apenas a versão mais recente da API em produção recebe atualizações de segurança e patches ativos.

| Versão | Suportada |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Como reportar uma vulnerabilidade

**Por favor, não relate vulnerabilidades de segurança através de issues públicas no GitHub.**

Se você acredita ter encontrado uma vulnerabilidade de segurança no Legato (seja na API, no banco de dados ou integrações de terceiros), pedimos que a relate diretamente para a nossa equipe de forma privada.

1. Envie um e-mail detalhado para: `security-reports@legatoapp.com` (ou "gabriel.santana@fatec.sp.gov.br")
2. Inclua na mensagem:
   - Uma descrição clara da vulnerabilidade.
   - Os passos necessários para reproduzir o problema (PoC - Proof of Concept).
   - O impacto potencial caso a vulnerabilidade seja explorada.

### Tempo de Resposta
Nossa equipe fará o possível para confirmar o recebimento do seu relatório em até **48 horas**. Após a triagem, forneceremos um prazo estimado para a correção da falha e publicação do patch de segurança. 

Agradecemos a todos os pesquisadores de segurança e avaliadores acadêmicos que nos ajudam a manter o ecossistema do Legato seguro!
